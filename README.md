# Polyrhythm Studio

Interactive browser-based geometric polyrhythm drum machine.

## Features
- Circular 3:5 polygon visualizer with clickable beat vertices
- Eight-track step sequencer
- Built-in synthesized drum audio
- BPM and swing controls
- Preset patterns and WAV/JSON export
- Runs directly in a browser without installing dependencies

## Use
Open `index.html` in a modern browser. Press Play, adjust the rhythm and click polygon vertices to toggle beats.

## Hosting
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
